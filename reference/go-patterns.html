Two Pointers

Recognize whenSorted array/string; searching for a pair/triplet meeting a target; palindrome check; merging two sorted sequences; want O(n) instead of an O(n²) nested-loop brute force.
VariantsOpposite ends — pointers start at both ends, move inward. Same direction — a slow pointer and a fast pointer both move forward, fast doing the exploring.
ComplexityO(n) time, O(1) extra space — the whole point versus the O(n²) brute force.
// Opposite-ends template — e.g. Two Sum II (sorted input)
func twoSum(nums []int, target int) []int {
    lo, hi := 0, len(nums)-1
    for lo < hi {
        sum := nums[lo] + nums[hi]
        switch {
        case sum == target:
            return []int{lo, hi}
        case sum < target:
            lo++
        default:
            hi--
        }
    }
    return nil
}

// Same-direction template — e.g. remove duplicates in place
func removeDuplicates(nums []int) int {
    slow := 0
    for fast := 1; fast < len(nums); fast++ {
        if nums[fast] != nums[slow] {
            slow++
            nums[slow] = nums[fast]
        }
    }
    return slow + 1
}

Drill problems: Two Sum II, Valid Palindrome, Container With Most Water, 3Sum, Remove Duplicates from Sorted Array, Trapping Rain Water.
